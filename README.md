# 사진관

사진·영상을 옛날 사진, 픽셀, 인쇄물, 그림, 디지털 효과로 바꿔 주는 웹앱입니다.
AI로 다시 그리지 않고, 브라우저 안에서 코드로만 변환합니다. 파일은 서버로 보내지 않습니다.

## 쓰는 법
`index.html`을 브라우저(크롬 추천)로 열기 → 사진이나 영상 넣기 → 효과 고르기 → 저장

## 효과 (33개)
1. 옛날 사진: 세피아, 70년대 필름, 바랜 컬러, 흑백 필름, 일회용 카메라, 폴라로이드, 날짜 도장, 청사진, 은판 사진
2. 도트·게임: 픽셀 5종, 글자 그림, 블록 모자이크, 십자수, 비즈 공예
3. 인쇄물: 만화책 망점, 신문 인쇄, 실크스크린, 리소 인쇄, 복사기
4. 그림: 연필 스케치, 색연필, 만화풍, 유화, 수채화, 포스터
5. 디지털: 옛날 TV, VHS 비디오, 글리치, 열화상, 야간투시경

영상은 가벼운 효과만 쓸 수 있고, 재생하면서 녹화해 720p로 저장합니다.
